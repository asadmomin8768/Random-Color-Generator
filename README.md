# Random Color Generator

A simple and interactive **Random Color Generator** that generates unique colors instantly.

## ✨ Features

* Generate random colors
* Display HEX color codes
* One-click color generation
* Simple and responsive interface

## 🛠️ Technologies Used

* HTML
* CSS
* JavaScript

## 🚀 How to Run

1. Clone or download the repository.
2. Open the project folder.
3. Open `index.html` in your web browser.

## 📌 Purpose

This project was created to practice **JavaScript DOM manipulation and dynamic styling**.
